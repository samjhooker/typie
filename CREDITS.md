# Credits

typie is built on the shoulders of some wonderful open-source projects. Thank you!

## Runtime dependencies

- [Svelte](https://svelte.dev) — MIT — the entire web UI is Svelte 5
- [bits-ui](https://www.bits-ui.com) — MIT — headless accessible primitives (tabs, switch, toggle groups)
- [DiceBear](https://www.dicebear.com) — default speaker avatars use the **Blobs** style (CC0 / [license](https://www.dicebear.com/licenses/)), generated on-device via `@dicebear/core` + the vendored `@dicebear/styles` definition. No network calls — avatars are created locally.
- [lucide-svelte](https://lucide.dev) — ISC — interface icons

## Build-time tooling

- [simple-icons](https://simpleicons.org) — CC0 — brand glyphs (Claude, OpenAI) in the "copy for LLM" button
- [Vite](https://vitejs.dev) — MIT — bundler
- [Prettier](https://prettier.io) + prettier-plugin-svelte — MIT — formatting

## Fonts

- Caveat, IBM Plex Mono, Inter — bundled in the resource pack (see their respective OFL/licence files)
